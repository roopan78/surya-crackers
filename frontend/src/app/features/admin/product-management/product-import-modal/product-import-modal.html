Use this template to ensure your products are imported correctly.

Before You Import

  • Use the provided sample template — the first worksheet is imported and column headers must not be renamed.
  • Each row is one product; empty rows are ignored automatically.
  • SKU, Category, Product Name and Price are required. Everything else is optional.
  • SKU is the unique identifier: existing SKUs update products, new SKUs create them.
  • Categories are matched case-insensitively; missing categories are created automatically.
  • Featured/Active accept TRUE/FALSE, YES/NO or 1/0.
  • Invalid rows never stop the import — they are skipped and reported.

Important

  • Existing products are updated using SKU — a blank optional cell keeps the current value.
  • New SKUs create new products; categories are created automatically.
  • Invalid rows are skipped. Large imports may take several seconds.
